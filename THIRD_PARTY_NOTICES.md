# Source and license history

The repository LICENSE supplied by the project owner is retained (MIT).
Inherited algorithms were developed in the owner's related projects and distributed development snapshots. See SOURCE_PROVENANCE.json for exact source versions and file hashes.

PotteryVolumeCalculator and PotteryReconstruction3D upstream repositories carry CC0 1.0 licenses. Their original CC0 grants remain applicable to those source versions. ArtefactsOrthoMaker switched from CC0 to MIT at v0.4.10, without retroactive changes.

Surface Enhancement Lab v0.7.3 and the reconstruction development snapshots originate from the project owner's previously distributed files. Their source code is preserved with origin and version information; they are not presented as a new validated stable release.

Third-party Python dependencies retain their own licenses and are not vendored.
